How the algorithm works

Simple data structures solving a familiar problem.

1. Group with a hash map

Read each expense once and add its amount to the matching category total. This takes O(n) time for n transactions.

2. Rank with merge sort

Sort the k category totals from largest to smallest. Merge sort takes O(k log k) time and gives a predictable ranking.

3. Compare with a budget

For each category, compare its total to the saved limit and show the percentage used. This helps someone notice overspending early.

PocketSort is a learning project. Data is stored locally in this browser and is not sent to a server.
